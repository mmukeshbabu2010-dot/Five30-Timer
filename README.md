# Five30 Timer ⏱️

Five30 Timer is a sleek, lightweight web-based repeating interval timer designed to keep you focused during study sessions, writing, and structured work blocks.

## 🚀 Features

- **Repeating 5:30 Cycles**: Counts down 5 minutes and 30 seconds automatically and restarts the loop until stopped.
- **Push Notifications**: Triggers native desktop/mobile system notifications at the end of each round.
- **Audio Alerts**: Plays a clean audio tone at the completion of each interval.
- **Full Control**: Includes Start, Pause/Resume, and Reset controls.
- **Round Counter**: Tracks total completed rounds during your session.

## 🛠️ How to Use

1. Open `index.html` in any modern web browser or deploy it via GitHub Pages.
2. Grant notification permissions when prompted to receive completion alerts.
3. Click **Start** to begin your 5:30 interval.
4. Use **Pause** to freeze time and **Stop** to reset back to 05:30.
